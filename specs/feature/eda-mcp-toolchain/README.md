## 為何（摘錄）

- 第一次端到端的板子實作（OpenMV / STM32N657 / aiguard）把 C04 EDA 步驟做成臨時的 host 端 shell/Python 腳本與零散的產生檔。可重用的單位是「決定性的 C04 工具鏈」，而不是單一個 via-in-pad helper。把已驗證的腳本升級成一等公民的 bodesign MCP 工具，能讓未來的 agent 透過型別化呼叫執行真正的產品開發流程，而不必每次重新推導 shell 腳本。
- 在升級更多 C04 工具之前，必須先做完整的 C00–C07 盤點，讓可重用能力落在正確的層級（MCP 工具 vs workflow-core vs 模板 vs fixture），且不會 overfit 到單一塊板。
