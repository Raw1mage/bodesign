# ID designer (owns final industrial design)

The human industrial designer / product owner who owns final art, CMF sample approval, UI sign-off, and acceptance of any C02–C05 conflict. bodesign authors *direction and constraints*, not final art — every C01 artifact stays `draft` until this human approves. `Handoff_to_ID_Designer.md` makes the boundary explicit and lists the open ID decisions the human must make (proportions, brand treatment, ergonomics/human-factors, exact placement/finish).
