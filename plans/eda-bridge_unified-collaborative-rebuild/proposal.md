## Scope

### IN
- Product-baseline amendment; target contracts; migration and ownership map; staged acceptance and dispatch boundaries.
- Preserve and wrap existing fidelity, provenance, vault, occupancy, motif, multi-sheet and native-tool adapters.
- Separate functional circuit blocks from graphical motifs and engineering validation from drawing quality.

### OUT
- Code changes, commits, deployment, automatic plan graduation or new implementation authorization in this planning round.
- Editing active child-plan tasks, peer worktrees or consumer projects.

## Non-Goals

- A replacement KiCad editor, guaranteed novel-circuit correctness, arbitrary lossless bidirectional synchronization, or universal autonomous routing.
- Reopening deferred reverse reconstruction and broad ID/ME generation as prerequisites for the first delivery slice.

## Constraints

- No silent fallback; missing evidence, unsupported edits and unavailable tools remain explicit.
- Manufacturing release requires artifact-bound validation and explicit human approval.
- Current behavior remains available through named compatibility adapters until migration is accepted.
- Approved target architecture is not current runtime truth. This package may advance to designed only after its design artifacts pass the normal gates.

## What Changes

One master dependency/acceptance baseline governs convergence; child plans retain implementation ownership and historical evidence. The sequence is baseline, shared contracts, C03 delivery, human round-trip, bounded C04, then migration and broader capability expansion.

## Capabilities

### New Capabilities
- Artifact-bound verification and revision-aware change proposals.
- Explicit capability support matrix with tested, partial, unavailable and unmeasured scopes.

### Modified Capabilities
- Existing generators and checkers participate in one application delivery path through adapters.
- Readiness reports engineering coverage separately from file presence and document completion.
